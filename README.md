## Overview

I build full-stack web and desktop applications with Java, JavaScript, React, Next.js, and Node.js, with a strong focus on clean architecture and REST API design. Over the past year I've moved deeper into AI automation — designing RAG pipelines and LLM-integrated workflows with n8n, LangChain, and Pinecone that run in production, not just as demos.

**Currently:** building automation systems and full-stack products, open to freelance work and collaboration on backend, architecture, or AI-automation projects.
